# plan

> **Status:** COMPLETE
> **Cluster:** 01-meta
> **Type:** instructional

## Pathway

| Step | Skill | When |
|---|---|---|
| 1 | `plan` | Unsure which planning step applies |
| 2 | `plan-spec` | Before work: define success criteria |
| 3 | `plan-decompose` | Work spans several sessions or agents; also mid-task handoff when context is full |
| 4 | `plan-model-tier` | Delegating to sub-agents |
| 5 | `plan-verify` | Output exists and needs evaluation |

## Description
Picks the right planning step. The steps are separate skills so each can be used alone.

## When to skip steps

- **Skip spec** when the task is trivial or already fully defined.
- **Skip decompose** when the work fits one session.
- **Skip verify** when the output is exploratory; verify when it matters.
- Recurring preferences or corrections belong in memory or CLAUDE.md, not in a plan.
