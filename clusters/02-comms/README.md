# 02-comms — Communication

Skills for drafting and reviewing communication to peers, stakeholders, and executives.

---

## Skills

### [write](write/) ✅ complete
Improves a draft in one of three modes: tone check (annotation only), humanise (rewrite in
the owner's style), or exec (translate for CISO, C-suite, or board).
→ [Full documentation](write/README.md)

---

## Typical chain

```
write (exec)        if the audience is non-technical
        ↓
write (tone check)  verify tone for the recipient
        ↓
write (humanise)    final style pass for the channel
```
