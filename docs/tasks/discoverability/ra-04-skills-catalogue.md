# Task RA-04: Generate SKILLS.md instead of hand-maintaining the README index

> Status: pending
> Parent: discoverability and consolidation programme
> Model: haiku
> Fallback: sonnet
> Depends on: RA-02
> Effort: S
> Touches: `scripts/gen-catalogue.sh` (new), `SKILLS.md` (new), `README.md`, `.github/workflows/validate.yml`, `CHANGELOG.md`

## Objective
A script generates `SKILLS.md`, a one-page catalogue of every skill and its description,
and CI fails if the catalogue is stale. The hand-maintained Skills Index in `README.md`
is replaced by a link.

## Background
- The README Skills Index was missing 10 of 57 skills when reviewed. Hand-kept indexes rot.
- Every `SKILL.md` now starts with frontmatter:
  ```
  ---
  name: <name>
  description: "<text>"
  ---
  ```
- Each `SKILL.md` also has a line `> **Type:** action` or `> **Type:** instructional`
  (one skill, `session-skill-extractor`, has none: print `instructional`).
- Grouping: by cluster directory for now (RA-15 will rename skills; the script must not
  hard-code names, only read files).

## Context files
- `scripts/roadmap-collect.sh`: example of looping over `clusters/*/*/` in this repo's style.
- `README.md`: the `## Skills Index` section (from the heading down to the next `---` line) is what you replace.

## Steps
1. Create `scripts/gen-catalogue.sh` (`#!/usr/bin/env bash`, `set -euo pipefail`, header comment):
   - `cd` to repo root (`"$(dirname "$0")/.."`).
   - Build the catalogue in a temp file:
     ```
     # Skills catalogue

     > Generated by `scripts/gen-catalogue.sh`. Do not edit by hand.

     ## <cluster-dir-name>

     | Skill | Type | Description |
     |---|---|---|
     | `<name>` | <type> | <description> |
     ```
     One `##` section per `clusters/*/` directory, in sorted order; rows sorted by name.
     Escape any `|` in descriptions as `\|`.
   - End with a line `Total: <N> skills`.
   - Modes: no argument writes `SKILLS.md`; `--check` compares the generated text to
     the existing `SKILLS.md` and exits 1 with `SKILLS.md is stale: run bash scripts/gen-catalogue.sh` if different, else 0.
2. `chmod +x scripts/gen-catalogue.sh`, run it to create `SKILLS.md`.
3. In `README.md`, replace the whole `## Skills Index` section body (keep the heading)
   with:
   ```
   The full, generated list of skills with descriptions is in [SKILLS.md](SKILLS.md).
   In Claude Code, type `/` and start typing to filter; in Copilot Chat use `#skill-name`.
   ```
4. Add a step to the `structure` job in `.github/workflows/validate.yml`:
   ```yaml
         - name: SKILLS.md catalogue is current
           run: bash scripts/gen-catalogue.sh --check
   ```
5. `CHANGELOG.md` → `### Added`: `- scripts/gen-catalogue.sh generates SKILLS.md; README links to it instead of a hand-kept index.`

## Constraints
- Read-only over `clusters/`. No skill files change.
- Bash, `sed`, `awk`, `grep`, `sort` only.

## Done when
- [ ] `shellcheck scripts/gen-catalogue.sh` prints nothing.
- [ ] `grep -c '^| `' SKILLS.md` equals `ls -d clusters/*/*/ | wc -l`.
- [ ] `bash scripts/gen-catalogue.sh --check` exits 0; after appending a space to any frontmatter description it exits 1 (revert afterwards).
- [ ] `README.md` no longer contains a table under `## Skills Index`.
